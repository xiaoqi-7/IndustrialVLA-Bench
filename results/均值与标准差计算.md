## 2. 统一公式与计算顺序

R1、R2、R3 表示以下计算中的三个运行结果。对这三项输入计算总体标准差时，分母为 3。

```text
输入三个运行级分数：x1, x2, x3

mu     = (x1 + x2 + x3) / 3
var    = [(x1 - mu)^2 + (x2 - mu)^2 + (x3 - mu)^2] / 3
SD_pop = sqrt(var)
结果   = mu +/- SD_pop
```

这里的 ± 是三个运行级分数的总体标准差，不是最大偏差、极差、标准误或样本标准差。样本标准差的分母为 2，会得到 `SD_sample = sqrt(3/2) * SD_pop`，不能混用。

Clean LIBERO：每个运行先平均 Spatial、Object、Goal、Long 四个子套件。

```text
x_r = (Spatial_r + Object_r + Goal_r + Long_r) / 4
```

LIBERO-Plus：每个运行先平均六个非语言扰动维度，Language 不计入 Robust Avg.。汇总文件的 Total 是另一种指标，不能代替这里的六维平均。

```text
x_r = (Camera_r + Robot_r + Light_r + Background_r + Noise_r + Layout_r) / 6
```

LIBERO-Para：每个运行的成功数除以 4,092，乘 100 转为百分数，再跨三个运行计算。

```text
x_r = 100 * successes_r / 4092
```

## 6. OpenPI 两处 ± 的改动

这两处计算使用的 Clean 分数为 96.65、96.70、96.20。

第一处：Clean Average 的总体标准差为 0.224845626，故 **96.52 ± 0.62 应改为 96.52 ± 0.22**。

第二处：Clean-to-Para drop 先按同一运行相减，再对三个差值求总体标准差。

```text
d_r     = Clean_r - Para_r
mean_d  = (d1 + d2 + d3) / 3
SD_drop = sqrt([(d1 - mean_d)^2 + (d2 - mean_d)^2 + (d3 - mean_d)^2] / 3)
```

### OpenPI Clean-to-Para drop

计算输入：Clean 使用第 3 节分数；Para 使用第 5 节成功数。

```text
x1 = 96.650000000 - 100 * 2919 / 4092 = 25.315689150
x2 = 96.700000000 - 100 * 2921 / 4092 = 25.316813294
x3 = 96.200000000 - 100 * 2916 / 4092 = 24.939002933

mu = (25.315689150 + 25.316813294 + 24.939002933) / 3
   = 25.190501792
SD = sqrt([(25.315689150 - 25.190501792)^2
         + (25.316813294 - 25.190501792)^2
         + (24.939002933 - 25.190501792)^2] / 3)
   = sqrt(0.031626048798)
   = 0.177837141 -> 0.18 pp
mu +/- SD = 25.19 +/- 0.18
```

因此 **25.19 ± 0.12 应改为 25.19 ± 0.18 pp**。OpenPI 的 Para 成功率 **71.33 ± 0.05** 不变。不能把两个标准差直接相减，也不能忽略配对协方差后直接平方相加。
